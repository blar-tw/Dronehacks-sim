# talos-field

Field notes, analysis scripts and calibration artifacts from skybeta-05 work on 2026-11-07.

| Folder | What it is |
|---|---|
| `crash-2026-11-07-2243/` | Crash timeline from the 22:43 flight: attitude frames and timeline script |
| `crash-2026-11-07-blar/` | Crash timeline rebuilt from a bag, with camera frames |
| `imu-fusion/` | First VIO replay A/B harness: IMU time shift, arm guard, compare script |
| `imu-fusion-ab/` | Second A/B run and its results (`RESULTS.md`) |
| `oak-depth-cal/` | OAK depth sanity check |
| `pixhawk-accel-cal-2026-11-07/` | Pixhawk accel calibration attempts: parameter backups, guide JSON, STATUSTEXT logs |
| `skybeta-mc-mode/` | MC mode notes for skybeta, `talos_mc_executor` package, height-fix patches |
| `roscon25-px4-workshop-deck/` | ROSCon '25 PX4 workshop deck export, notes, and reference code (CC-BY-SA, see its `LICENSE`) |
| `tools/` | Mac-side helpers: Pixhawk-to-VM bridge, PX4 accel cal |

Left out of git: the workshop videos (`roscon25-px4-workshop-deck/videos/`, 2.7 GB; three files are over
GitHub's 100 MB limit) and `.zip` copies of folders that are already here.
